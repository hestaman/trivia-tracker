TRIVIA TRACKER v1.1 (development build)

Included:
- Solo trivia sessions with video title and planned question count
- Correct / incorrect taps, undo, finish early, and resume unfinished session
- Daily and lifetime statistics plus local history
- Saved Players list (name + phone stored locally on this device)

Important:
- Multiplayer shared scoring is not implemented yet. It requires a hosted shared database/realtime sync, invitation links, and a join flow. The Play Together option is intentionally disabled in this build so it doesn't imply a live shared game is already working.
- Saved player contacts are stored in this device's local browser storage. This is not a contacts integration and does not automatically send SMS.
- For iPhone installation, the app must be hosted on HTTPS, then open in Safari and use Share > Add to Home Screen.
- Your scores remain on this device/browser storage. Clearing Safari site data may erase them. Consider exporting/backing up before clearing data.
